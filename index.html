Workspace MCP

A personal, single-user automation tool.

Workspace MCP connects its owner's own Google account to a command-line assistant running on the owner's personal computer, so that routine personal tasks — reading the owner's own email, updating the owner's own spreadsheets, managing the owner's own calendar — can be automated.

It is not a commercial product. It is not distributed, sold, or offered to the public. There are no other users. The only accounts that authorize it are personal accounts belonging to the owner and the owner's immediate household.

How it works

The application runs entirely on the owner's local machine. It uses Google's official OAuth 2.0 flow to obtain the owner's consent, and Google's published APIs to read and write data in the owner's own account. Access tokens are stored on the local machine in files readable only by the operating-system account that owns them.

Scope of access

Depending on which features are used, the application may access the owner's Gmail, Google Drive, Docs, Sheets, Calendar, Tasks, and Contacts — in every case, only within the owner's own account, and only in response to a direct instruction from the owner.

Privacy

  • No data is transmitted to any server operated by the developer.
  • No data is sold, rented, traded, or shared with third parties.
  • No data is used for advertising or profiling.
  • No data is used to train or fine-tune any AI or machine learning model.
